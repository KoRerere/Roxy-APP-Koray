# Agent Guidelines & Rules

## 语言规范 (Language Requirement)
- **所有 AI Agent 在回答问题、编写实施计划、生成文档、编写代码注释以及与用户交互时，必须统一使用中文。**
- All responses, plans, documentation, and agent interactions MUST be in Chinese.

## 前端 CSS 规范 (CSS Style Requirement)
- **前端 Vue/HTML 页面及组件样式编写时，必须优先并尽量使用 UnoCSS 工具类类名，减少硬编码与冗余 SCSS/CSS 样式块。**
