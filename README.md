# Electron Vite Monorepo

An Electron + Vite Monorepo Demo

Uses:

- Vue.js
- Typescript
- Turborepo
- Vite (for Electron builds)

## Getting Started

```bash
pnpm install
pnpm run dev

# 生成语言文件
pnpm genLanguage

# 生成接口请求
pnpm openapi
```
