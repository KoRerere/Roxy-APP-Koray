# 更新日志

## 2025-01-14 - 基于 Figma 设计稿更新

### 更新内容

#### 1. 添加时间显示
- ✅ 每条消息都显示发送时间
- 格式：`YYYY/MM/DD HH:mm`（例如：2025/08/25 12:05）
- 时间显示在消息头部，用户名旁边

#### 2. 更新消息布局
根据 Figma 设计稿 (node-id=187-178) 进行了以下调整：

**之前的布局：**
- 用户消息：右对齐，蓝色气泡
- AI 消息：左对齐，灰色气泡
- 消息内容在气泡内

**现在的布局：**
- 用户消息和 AI 消息都左对齐
- 消息结构：头像 + 消息体
- 消息体包含：
  - 头部：用户名 + 时间 + 状态标签
  - 内容：白色背景，带边框的卡片样式
- 背景色：整体聊天区域使用 #f5f5f5 灰色背景

#### 3. 样式细节

**头像：**
- 用户头像：使用用户设置的颜色或默认蓝色
- AI 头像：紫色渐变背景 + 星星图标

**消息卡片：**
- 背景：白色 (#ffffff)
- 边框：1px solid #e5e7eb
- 圆角：8px
- 内边距：12px 16px

**状态标签：**
- 思考中：黄色背景 (#fef3c7)，棕色文字
- 成功：不显示标签（设计稿中成功状态无标签）
- 失败：红色背景 (#fee2e2)，红色文字

**时间戳：**
- 颜色：#9ca3af（灰色）
- 字体大小：12px

|------|--------|--------|
| 用户消息对齐 | 右对齐 | 左对齐 |
